# rknn

Fits random k-nearest-neighbor models for classification and regression.

Compatibility updates by Renova.

Uses DBL_MAX in the C implementation, declares R imports, and cleans up internal help and package metadata.

## Installation

```r
install.packages("rknn", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `1.2.1.9001` is based on [CRAN 1.2-1](https://cran.r-project.org/package=rknn).
